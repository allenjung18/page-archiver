# Import fixtures

Six pages in the shape SingleFile saves them (its header comment with the URL and the saved
date, styles and images inline, no scripts), for `pa import`. Each article carries one invented
word that appears nowhere else in the fixtures, so a search for it has exactly one right answer:

| file | word |
|---|---|
| sourdough-starter.html | wobbleloaf |
| chain-wear.html | quindlesprocket |
| moss-garden.html | frondlemist |
| review-lantern-coast.html | glimmerhaw |
| night-train-notes.html | drowsenhalt |
| http-caching-guide.html | plinkerstash |

The URLs are never fetched.
